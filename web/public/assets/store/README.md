# صور المتجر — كيف ترفعها

هذا المجلد هو المكان الوحيد الذي ترفع إليه صور المنتجات.
كل المجلدات **جاهزة مسبقاً** — لا تنشئ مجلداً جديداً بيدك.

---

## الخطوات

1. **افتح مجلد المنتج** باسم `productId`، مثل `geprc-cinelog35/`.
2. **افتح مجلد الخيار** بداخله.
   - إذا رأيت `_shared/` فهذا منتج تكفيه صورة واحدة لكل خياراته.
   - إذا رأيت عدّة مجلدات (`o4-pro/`, `wtfpv/`) فلكل خيار صوره.
3. **ارفع الصورة بالاسم المحدَّد بالضبط** — الأسماء مكتوبة في
   [`docs/store/PRODUCT_IMAGE_MANIFEST.md`](../../../../docs/store/PRODUCT_IMAGE_MANIFEST.md).
4. **لا تغيّر الامتداد.** `.webp` فقط.
5. **لا تضف مسافات ولا حروفاً عربية** إلى اسم الملف.
6. **استخدم WebP.** لا JPG ولا PNG.
7. **حافظ على النسبة `1:1`** — مربّعة.

---

## أسماء الملفات — سبعة، ثابتة على كل المنتجات

| الملف | ما الذي يُصوَّر |
| --- | --- |
| `01-main.webp` | المنتج كاملاً على خلفية بيضاء أو فاتحة. **إلزامية** |
| `02-front.webp` | من الأمام مباشرة |
| `03-side.webp` | من الجانب |
| `04-back.webp` | من الخلف — المنافذ والمخارج |
| `05-top.webp` | من الأعلى |
| `06-box.webp` | محتويات الصندوق كما تصل فعلاً |
| `07-accessories.webp` | الملحقات: بطاريات، مراوح، هوائيات |

الرقم مرتبط بالوظيفة لا بالترتيب. صورة الصندوق اسمها `06-box.webp` على كل
منتج، سواء طلب ذلك المنتج ثلاث صور أو سبعاً. تتعلّم سبعة أسماء مرّة واحدة
بدل مراجعة الجدول لكل ملف.

**لا ترفع صورة لم يطلبها المنتج.** الملف الزائد لا يظهر في أي مكان،
والاختبار يبلّغ عنه على أنه «صورة يتيمة».

## المواصفات

| البند | القيمة |
| --- | --- |
| الصيغة | `WebP` |
| النسبة | `1:1` |
| المقاس المفضّل | `1600×1600` |
| الحد الأدنى | `1000×1000` |
| الحجم الأقصى | `400KB` |

إن كان منتج يحتاج نسبة مختلفة فسيكون مسجَّلاً صراحةً في الـManifest.

---

## ما يحدث بعد الرفع

لا شيء عليك فعله. لا تعديل بيانات، ولا إدخال رابط في أي ملف.

- `01-main.webp` تظهر في بطاقة المنتج.
- بقيّة الصور تظهر في معرض صفحة المنتج بترتيب أرقامها.
- تغيير الخيار في صفحة المنتج يبدّل الصور إلى مجلد ذلك الخيار.
- المنتج الذي لم تُرفع صوره بعد يعرض عنصراً نائباً واضحاً يقول ذلك —
  لا صورة منتج آخر، ولا مربّعاً رمادياً بلا تفسير.

---

## حقوق الصور

ارفع صوراً تملك حقّ نشرها: صورة الشركة الصانعة بإذنها، أو صورتك أنت.
**لا صوراً مولَّدة بالذكاء الاصطناعي، ولا صوراً منسوخة من متاجر أخرى.**

---

## التحقّق

```bash
npx tsx scripts/testStoreImages.ts
```

يبلّغك بأربع حالات لكل ملف:

| الحالة | المعنى |
| --- | --- |
| `expected but not uploaded` | مطلوبة ولم تُرفع بعد — طبيعي الآن |
| `uploaded and valid` | مرفوعة وباسم صحيح |
| `orphan` | ملف لا يطلبه أي منتج |
| `invalid` | اسم أو امتداد لا يطابق النمط |
