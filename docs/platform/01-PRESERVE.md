# 2. قائمة ما يجب الحفاظ عليه (عقد حماية)

هذه القائمة عقد ملزم. أي عمل لاحق على هذا المشروع لا يجوز أن يحذف أو يعطّل أياً من البنود التالية دون موافقة مكتوبة صريحة من مالك المشروع، مع سبب موثّق.

## 2.1 يُحفَظ كما هو — لا يُمَس (Frozen)

| المكوّن | المسار | لماذا |
|---|---|---|
| هوية التطبيق | `capacitor.config.ts` (`com.fpvarabic.app`) | ممنوع تغيير Application ID |
| وحدة Android الوحيدة | `android/` | ممنوع إنشاء وحدة ثانية أو APK منفصل |
| نظام المصادقة | `src/contexts/AuthContext.tsx`, `src/components/Auth/` | يعمل في الإنتاج |
| نظام المجتمع بالكامل | `src/components/Community/**` (49 ملفاً) | يعمل في الإنتاج مع Firestore |
| قواعد Firestore والتخزين | `firestore.rules`, `storage.rules`, `firestore.indexes.json` | منشورة فعلياً |
| دوال Firebase | `functions/` | منشورة فعلياً |
| نظام تصميم CSS | `src/index.css` | مشترك بين كل الشاشات |
| كل سكربتات الاختبار الـ60 | `scripts/` | الدليل الوحيد على صحة الميزات القائمة |
| كل الأصول | `public/assets/**`, `public/build-images/**`, `resources/` | صور مرفوعة يدوياً |
| القواعد الهندسية | `docs/ENGINEERING_RULES.md` | عقد عملية قائم |

## 2.4 يُصلَح — عطل مؤكد

| العطل | الموقع | الإصلاح |
|---|---|---|
| زر "عرض تحذير السلامة" يؤدي إلى 404 | `SettingsView.tsx:27` → `/safety` غير مسجَّل في `App.tsx:34` | إما تسجيل المسار أو إزالة الزر — لا يُترك معطوباً |

## 2.5 ممنوعات مطلقة

- ❌ حذف أي ملف في `src/components/Community/` أو `functions/` أو `android/`.
- ❌ تغيير `applicationId` أو اسم الحزمة.
- ❌ إنشاء تطبيق ثانٍ أو وحدة Android ثانية أو Hardware Test App منفصل.
- ❌ `git reset --hard` أو `git push --force` على فرع فيه عمل غير مدموج.
- ❌ استبدال مكوّن يعمل بمكوّن جديد غير مكتمل.
- ❌ تعليم قسم بأنه "مكتمل" قبل وجود اختبار يمرّ فعلاً.
- ❌ حذف محتوى مؤلَّف — يُنقَل أو يُعاد استخدامه، لا يُحذف.
