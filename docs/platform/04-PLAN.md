## 13. معايير القبول (بوابة صارمة)

الوحدة لا تُعتبر مكتملة إلا إذا تحقق كل ما يلي، وكل بند منها **قابل للتحقق آلياً أو بدليل خام**:

**المحتوى**
1. كل مقال ≥ 4 كتل محتوى فعلية، و`summaryAr` غير فارغ.
2. كل مقال يعلن `coverage` غير فارغة، وكل محور معلن مدعوم بكتلة فعلية.
3. الوحدة تغطي كل محور في `requiredCoverage` — أو يظهر النقص صراحةً للمستخدم.
4. كل مقال له `sources[]` و`lastReviewed`.
5. لا يوجد نص «قريباً» أو `Lorem` أو بيانات وهمية داخل أي مقال.
6. كل مقال يخدم مستوى مبتدئ ومستوى متقدم عبر الطبقات.

**الترابط**
7. كل `relatedArticleIds` و`prerequisiteIds` و`glossaryIds` و`links` تشير إلى أهداف موجودة فعلاً (اختبار سلامة مرجعية).
8. كل مقال قابل للوصول عبر البحث.
9. كل شجرة تشخيص مرتبطة بمقال واحد على الأقل، وكل عقدة فيها لها ≥ 2 احتمال.

**التنفيذ**
10. `npm run build` ينجح.
11. اختبار المنطق يمرّ (سكربت `tsx`).
12. اختبار Playwright يمرّ ضد بناء إنتاجي طازج.
13. كل مسار جديد يعمل وكل زر يؤدي وظيفته.
14. لا تراجع في أي وظيفة قائمة (اختبار تنقّل يثبت بقاء التبويبات الخمسة القديمة).
